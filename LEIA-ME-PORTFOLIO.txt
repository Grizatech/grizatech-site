GRIZATECH SITE V14 — COMO ADICIONAR FOTOS AO PORTFÓLIO
========================================================

1. Prepare a nova imagem em JPG, de preferência com 1600 x 900 px.
2. Use o próximo nome no formato cliente-XX.jpg.
   Exemplos: cliente-06.jpg, cliente-07.jpg, cliente-08.jpg.
3. Envie o arquivo para assets/portfolio/ no GitHub.
4. Faça o commit e aguarde a atualização do GitHub Pages.

Pronto. Não é necessário editar portfolio.js, index.html ou qualquer outro arquivo.

A galeria procura automaticamente cliente-01.jpg até cliente-99.jpg, ignora
números ausentes, atualiza o contador e mostra todos os arquivos encontrados.
Os cinco primeiros cards ficam no destaque visível; os demais ficam na mesma
galeria e podem ser acessados pela barra de rolagem horizontal.

A ordem permanece estável por dois dias. Na janela seguinte, ela muda de forma
determinística para alternar os trabalhos entre destaque e rolagem.

Cada card recebe automaticamente:
- MONTAGEM CLIENTE XX
- Trabalho realizado pela GrizaTech.

Ao clicar em AMPLIAR +, o lightbox continua abrindo a imagem em tamanho maior.

IMPORTANTE
----------
- Use somente JPG com o nome exato cliente-XX.jpg.
- Use números de 01 a 99.
- Letras minúsculas e hífen fazem parte do padrão.
- Não altere os arquivos de Firebase, feedbacks, admin ou vídeo para adicionar fotos.
